# Frontend Policy Index

Use this index to select the reference files you need.

## Quick Picks by Task

- Start with component and state foundations:
  - `fundamentals/FRONTEND_COMPONENT.md`
  - `fundamentals/FRONTEND_STATE.md`
- Plan routing and data loading:
  - `fundamentals/FRONTEND_ROUTING.md`
  - plus framework routing reference under `frameworks/*`
- Implement i18n and copy strategy:
  - `fundamentals/FRONTEND_I18N.md`
- Validate accessibility:
  - `fundamentals/FRONTEND_ACCESSIBILITY.md`
  - `fundamentals/FRONTEND_A11Y_SEMANTICS.md`
  - `fundamentals/FRONTEND_A11Y_INTERACTION.md`
  - `fundamentals/FRONTEND_A11Y_VISUAL.md`
